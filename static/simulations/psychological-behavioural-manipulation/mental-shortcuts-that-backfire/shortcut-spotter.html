The Shortcut Spotter

Meera has been getting messages from a "market analyst" for weeks. Each message uses a different mental shortcut to earn her trust. Spot which one is at work before you decide what to do.

Step 1 of 5

What Every Choice Revealed

  • Mere exposure makes repeated, harmless-looking contact feel like familiarity - familiarity is not verification.
  • The Barnum effect makes vague, flattering language feel personally written for you. It is written for everyone.
  • Anchoring makes any later number look reasonable once an earlier number has set the frame.
  • The halo effect lets one polished signal - a title, a photo, a confident voice - imply trustworthiness that was never actually demonstrated.
  • Framing changes how persuasive the same fact feels, purely based on the words used to describe it.
